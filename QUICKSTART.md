# Quick Start Guide

## 🚀 Run Locally in 3 Steps

### Step 1: Clone
```bash
git clone https://github.com/reda10nafil/atomizer.git
cd atomizer
```

### Step 2: Install
```bash
npm install
```

### Step 3: Run
```bash
npm run dev
```

Open `http://localhost:3000` in your browser.

## 🎮 First Time Usage

1. **Select a mode** from the left panel (try "Galaxy" 🌌 first)
2. **Adjust sliders** to see real-time changes
3. **Move your mouse** over the canvas to interact
4. **Click and drag** to rotate the view
5. **Scroll** to zoom in/out

## ⌨️ Keyboard Shortcuts

- `Space` - Play/Pause
- `R` - Reset settings
- `H` - Hide/Show UI

## 📱 Tested Browsers

## 🐛 Troubleshooting

### Low FPS?
- Reduce particle count to 100k or less
- Close other browser tabs
- Update GPU drivers

### Black screen?
- Check browser console for errors
- Ensure WebGL is enabled
- Try a different browser

### Can't see particles?
- Click and drag to rotate view
- Scroll to zoom out
- Reset with `R` key
